Everything here is public and runnable. Each README states what the tool does, the real failure it repairs, and what it cannot do.

## LLM applications

### [rag-support-bot](https://github.com/uhygyuf/rag-support-bot)
Support chatbot that answers from a company's own documents (real business content, not dummy data), says "I don't know" instead of inventing an answer, and files a ticket for a human.

`n8n` · `Supabase pgvector` · `DeepSeek`

### [AIMail](https://github.com/uhygyuf/AIMail)
Gmail auto-classification: an LLM reads sender, subject and body, then stars, archives or leaves each message alone according to rules written in plain language.

`Google Apps Script` · `DeepSeek`

### [fiverr-agent-demo](https://github.com/uhygyuf/fiverr-agent-demo)
LLM triage that classifies customer messages into order / support / refund / complaint / spam and drafts a reply in the customer's language.

`Python`

## Teaching a course, with software

### [algorithm-class-demos](https://github.com/uhygyuf/algorithm-class-demos)
Eleven interactive visualisations for a data structures course — the lecture's own C++ code executed frame by frame, with the call stack drawn and a recursion tree that grows as you step.

[**Live demo →**](https://uhygyuf.github.io/algorithm-class-demos/)

`HTML` · `CSS` · `JavaScript`

## Systems utilities

### [service-tunnel-watchdog](https://github.com/uhygyuf/service-tunnel-watchdog)
Keeps a local service **and** its public tunnel alive on Windows, and re-registers the service when the tunnel comes back with a new hostname.

`PowerShell`

### [zombie-window-cleaner](https://github.com/uhygyuf/zombie-window-cleaner)
Closes the orphaned console windows that service launchers leave behind, on a schedule, without ever touching the service that is still running.

`PowerShell`
